# Jordan Lee Portfolio

A simple personal portfolio website built with HTML and CSS.

## Overview

This project showcases a junior developer portfolio with:
- a hero section
- about section
- project cards
- skills list
- contact call-to-action

## Files

- `index.html` — page structure and content
- `style.css` — styling and layout
- `IMG_20260219_165108_311.jpg` — profile image used in the hero section

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
cd /home/harry/my-portfolio
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a lightweight static site and does not require a build step or package installation.
